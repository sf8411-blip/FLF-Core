# FLF-Core

Core repository for the digital-cell / decentralized learning research program.

## SMAA 0.1.0 — functional self-modeling foundation

An isolated, standard-library Python prototype is provided in `smaa/`. It tracks network identity, cell membership, capability evidence, knowledge provenance, prediction calibration and reasoned self-model revision. It includes a process-separated cell message boundary.

SMAA is a functional software self-model, not a claim of phenomenal consciousness or human-like subjective experience.

Run the test suite:

```bash
python -m unittest discover -s tests -v
```

See [SMAA architecture](docs/SMAA_ARCHITECTURE.md) and [test protocol](docs/SMAA_TEST_PROTOCOL.md).
